# sriinnu's Homebrew tap

Casks for macOS apps shipped by [@sriinnu](https://github.com/sriinnu).

## Install

```bash
brew install sriinnu/tap/<cask-name>
```

## Available casks

| Cask | App | Source |
|---|---|---|
| `mimo` | Mimo — menu-bar git identity switcher with a mascot | [sriinnu/Mimo](https://github.com/sriinnu/Mimo) |
| `portpilot` | PortPilot — menu bar port manager with kill, proxy, and cron control | [sriinnu/portpilot](https://github.com/sriinnu/portpilot) |
| `tokmeterbar` | TokmeterBar — menu-bar token usage tracker for AI coding agents | [sriinnu/tokmeter](https://github.com/sriinnu/tokmeter) |

## Updating

Casks auto-update via Sparkle once installed. For new versions through Homebrew:

```bash
brew upgrade
```
